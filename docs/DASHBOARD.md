# Dashboard Settings

This document describes the configurations of the `dashboard` application, a user interface (`UI`) used to manage the settings and commands of the `IIoTGateway`.

In the same network the dashboard can be accessed by the `IIoTGateway` hostname: [iiotgateway.local](http://iiotgateway.local)

## Login:

Default login:

- **Username:** `admin`
- **Password:** `gtwAdmin`

![Login screen](/docs/images/dashboard_login.png)

**Note:** A feature for changing `username` and `password` is planned (By now it works only with the default values).

## Communication

On the `Communication` menu is where `Cloud` and `Edge` protocols are configured:
